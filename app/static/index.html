System Architecture & Theoretical Formulation

Physical principles of millimeter-wave wireless propagation assisted by anomalous metasurface reflections.

Channel Path A: Direct Link
h_direct (AP → UE)
Direct electromagnetic line-of-sight path. For any fixed user terminal coordinate, its path loss and tap energy remain invariant to the RIS configuration state.
Channel Path B: RIS Link
h_RIS (AP → RIS → UE)
Cascaded dyadic reflection link steered by N programmable phase-shift elements. Received power in the far field scales with the cascaded product: ∼ 1 / (d_AP-RIS · d_RIS-UE)².
Channel Path C: Composite
h_comp = h_dir + h_RIS
Complex vector superposition of both paths. Exhibits constructive reinforcement when phases align or destructive partial cancellation when phase differences approach 180 degrees.
Methodological Validation & Target Status Note
The dataset target column is officially designated Path_Loss_With_RIS_dB_PROVISIONAL with target status PROVISIONAL_UNVERIFIED. Audits confirm that these target quantities are mathematically derived from ray-tracing channel tap energies via the exact formula: Path_Loss_dB = -10 × log10(Tap_Energy). The fundamental conservation law RIS_Gain = Path_Loss_No_RIS - Path_Loss_With_RIS holds to machine precision (discrepancy ≤ 5.00 × 10^-8 dB). These values represent internally consistent, dataset-derived simulation targets without uncalibrated hardware measurement claims.
